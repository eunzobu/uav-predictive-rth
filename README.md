# UAV Predictive RTH

위치와 잔여 에너지를 고려해 UAV의 귀환 시점을 판단하는 연구입니다. IoT 환경의 데이터 수집 임무에서 비행 시간과 귀환 가능성을 함께 고려했습니다.

## 연구 문제

비교 기준으로 사용한 Threshold RTH는 배터리 잔량 20%를 기준으로 귀환을 판단했습니다. 같은 잔량이라도 기지점까지의 거리가 다르면 귀환에 필요한 에너지가 달라질 수 있어, 거리와 잔여 에너지를 함께 고려했습니다.

## 본인 기여

Threshold RTH의 한계를 분석하고, Predictive RTH를 구현해 MATLAB 기반 타임 슬롯 시뮬레이션으로 비교했습니다.

```text
Safety Margin = 현재 에너지로 이동 가능한 최대 거리 - 기지점까지의 거리
```

각 시간 슬롯에서 위치와 잔여 에너지를 갱신합니다. 이동 가능한 최대 거리가 기지점까지의 거리 이하가 되면 귀환을 판단합니다.

## 실험 결과

2026년 9월 10일 발표자료에 수록한 시뮬레이션 실행 결과입니다.

| 비교 항목 | Threshold RTH | Predictive RTH |
| --- | ---: | ---: |
| 귀환 판단 시점 | 4126.40 s | 4099.30 s |
| 판단 시 배터리 잔량 | 20.00% | 20.71% |
| Lap | 11.37 | 11.27 |

해당 실행에서 Predictive RTH는 고정 임계값 방식보다 27.10초 먼저 귀환을 판단했습니다. 위치 변화에 따라 귀환 판단 시점이 달라지는 것을 확인했습니다. 이 수치는 한 시뮬레이션 조건의 결과이며, 실제 비행 안전성이나 일반적인 성능 향상을 의미하지 않습니다.
