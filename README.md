# UAV Predictive RTH

위치와 잔여 에너지를 고려해 UAV의 귀환 시점을 판단하는 시뮬레이션 연구입니다.

## 연구 문제

비교 기준으로 사용한 Threshold RTH는 배터리 잔량 20%를 기준으로 귀환을 판단했습니다. 같은 잔량이라도 기지점까지의 거리가 다르면 귀환에 필요한 에너지가 달라질 수 있어, 거리와 잔여 에너지를 함께 고려했습니다.

## 본인 기여

Predictive RTH 방식을 제안하고 MATLAB 기반 타임 슬롯 시뮬레이션으로 비교했습니다. 연구 내 판단 지표를 다음과 같이 정의했습니다.

```text
Safety Margin = 현재 에너지로 이동 가능한 최대 거리 - 기지점까지의 거리
```

시뮬레이션의 이동 가능 거리 모델에 따른 지표입니다. 실제 비행의 안전성을 검증한 결과와는 구분합니다.

## 비교 방법

시간 슬롯별 위치, 거리와 에너지를 갱신하고 두 방식의 귀환 시점, 잔량, 위치와 Lap을 비교했습니다. 배터리 변화와 거리 그래프로 판단 시점을 확인했습니다.

## 공개 범위와 한계

현재는 연구 설명 문서입니다. 시뮬레이션 코드와 원본 실험 자료는 포함하지 않았습니다. 결과 수치와 개선율은 실험 조건 및 로그를 확인한 뒤 추가할 예정입니다. 실기체 검증은 포함하지 않습니다.

재현 자료에는 에너지 모델, 비행 조건, 정확한 귀환 발동 조건과 결과 그래프를 함께 정리할 예정입니다.
